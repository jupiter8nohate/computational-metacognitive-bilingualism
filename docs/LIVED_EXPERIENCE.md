# Why I Write This Way

## Autism, Schizophrenia & Computational Metacognitive Bilingualism

**Jupiter Hudson**  
*WisdomLoveThePoet / Jupiter 8*  
Creator of **Computational Metacognitive Bilingualism (CMB)**

> **Scope:** This page is a first-person account of my lived experience. It is not medical advice, a diagnostic guide, or a claim that every autistic person or every person with schizophrenia thinks as I do.

```text
DIAGNOSIS != IDENTITY
PROFILE != PERSON
MODEL != MIND
LABEL != TOTALITY
HUMAN_AGENCY > MACHINE_AUTHORITY
```

## 01 // The human behind the code

I use the words **autism**, **Asperger syndrome**, and **schizophrenia** when describing important parts of my own history and lived experience.

Those words can describe diagnoses or clinical categories. They do not contain the total architecture of a person.

My work often appears as code, symbols, equations, arrows, visual hierarchies, poetry, philosophical analogies, repeated invariants, and unusual conceptual connections. That form is intentional. It is one of the ways I translate thought into something I can inspect.

```text
EXPERIENCE
   ↓
PATTERN
   ↓
SYMBOL / LANGUAGE / CODE
   ↓
QUESTION
   ↓
VERIFY
   ↓
HUMAN JUDGMENT
```

## 02 // Autism and systems

In my own experience, autistic cognition often pushes me toward systems, structures, relationships, repeated forms, and explicit rules.

Programming language became useful because programming already contains structures that resemble the way I naturally organize concepts:

```text
IF
THEN
ELSE

INPUT
PROCESS
OUTPUT

ASSERT
VERIFY
RETURN

CAUSE?
EVIDENCE?
CONCLUSION?
```

That is part of why I began using code for more than software. I use it as poetry, visual structure, philosophy, advocacy, and metacognitive notation.

The code is not meant to reduce human experience to computation.

It does the opposite.

It uses the machine's rigid language to mark the limits of machine authority.

## 03 // Schizophrenia and the question of reality

My experience with schizophrenia gives one CMB principle unusual weight:

> **PATTERN ≠ PROOF**

A connection can feel powerful.

A coincidence can feel significant.

A symbol can carry enormous subjective meaning.

An idea can arrive with extraordinary intensity.

But intensity alone does not establish external truth.

```text
SIGNIFICANCE != EVIDENCE
FEELING      != FACT
PATTERN      != PROOF
CERTAINTY    != VERIFICATION
```

That does not make subjective experience meaningless. It means different categories require different standards.

```text
subjective_meaning = HUMAN_DOMAIN
external_claim     = EVIDENCE_DOMAIN
```

I can preserve the meaning of an experience while still asking whether an external claim is supported by evidence.

That boundary is central to CMB.

## 04 // Why CMB exists

Computational Metacognitive Bilingualism became a translation layer between experience and verification.

```text
HUMAN EXPERIENCE
      │
      ▼
   OBSERVE
      │
      ▼
   EXPRESS
      │
      ▼
      CMB
      │
      ▼
   QUESTION
      │
      ▼
    TRACE
      │
      ▼
   VERIFY
      │
      ▼
HUMAN JUDGMENT
```

CMB gives me a way to preserve an unusual idea without automatically declaring that idea true.

The architecture is simple:

```text
PATTERN -> HYPOTHESIS
HYPOTHESIS -> TEST
TEST -> EVIDENCE
EVIDENCE -> PROVISIONAL CONCLUSION
```

And when evidence is insufficient:

```text
UNKNOWN != ERROR
```

## 05 // My epistemic firewall

These are some of the core boundaries I use:

```text
PATTERN != PROOF
PROFILE != PERSON
MODEL != MIND
PREDICTION != DESTINY

OBSERVATION != UNDERSTANDING
SIGNAL != SOURCE
VERIFIED_LABEL != VERIFIED_TRUTH

MACHINE_CAN_READ != MACHINE_CAN_DEFINE
HUMAN_AGENCY > MACHINE_AUTHORITY
```

The point is not to suppress unconventional thought.

The point is to give unconventional thought a method for interrogating itself.

A practical version looks like this:

```text
experience
    ↓
observe
    ↓
record
    ↓
separate interpretation from fact
    ↓
identify the claim
    ↓
trace the source
    ↓
seek independent evidence
    ↓
look for counterevidence
    ↓
attempt falsification
    ↓
verify or label UNKNOWN
    ↓
retain human meaning
```

## 06 // CMB as metacognition

Metacognition means thinking about thinking.

CMB gives that process an explicit computational form:

```text
THOUGHT
   ↓
OBSERVE(THOUGHT)
   ↓
CLASSIFY_CLAIM_TYPE()
   ↓
CHECK_ASSUMPTIONS()
   ↓
SEARCH_FOR_EVIDENCE()
   ↓
CHECK_COUNTEREVIDENCE()
   ↓
UPDATE_CONFIDENCE()
```

In plain language:

> **My mind may generate the connection. CMB asks whether reality confirms the connection.**

That sentence captures one of the deepest reasons I created this framework.

## 07 // Art and evidence are different layers

Verification does not eliminate imagination.

I can turn experience into:

```text
poetry
symbols
glyphs
geometry
code
metaphor
fiction
philosophy
visual art
```

without asserting:

```text
ARTISTIC_MEANING == SCIENTIFIC_FACT
```

CMB keeps two semantic layers visible:

```text
CREATIVE_LAYER
      │
      ├── metaphor
      ├── symbolism
      ├── imagination
      └── subjective meaning

EVIDENCE_LAYER
      │
      ├── sources
      ├── measurements
      ├── reproducibility
      ├── counterevidence
      └── falsification
```

Neither layer needs to destroy the other.

## 08 // Neurodivergence without mythology

I do not claim:

```text
AUTISM        == GENIUS
SCHIZOPHRENIA == CREATIVITY
DIAGNOSIS     == DESTINY
```

Those equations would reduce complex human beings to stereotypes.

I can testify only about myself.

My neurological and psychiatric experiences are part of the environment in which this work developed. They are not universal explanations for creativity, intelligence, spirituality, or identity.

```text
PERSON > DIAGNOSIS
EXPERIENCE > STEREOTYPE
DIFFERENCE != DEFECT
```

## 09 // Why I write this way

I use rigid machine syntax to express experiences that machines cannot own.

I use code to talk about poetry.

I use mathematics to question certainty.

I use symbols to represent experiences ordinary sentences sometimes fail to contain.

I use verification to protect imagination from being mistaken for evidence.

And I use CMB to maintain the boundary between what a system can calculate and what a human being retains the authority to mean.

```text
MACHINE_CAN = {
    observe,
    classify,
    calculate,
    predict,
    generate,
    simulate
}

HUMAN_RETAINS = {
    meaning,
    consent,
    judgment,
    authorship,
    dignity,
    self_definition
}
```

Therefore:

```text
PATTERN != PROOF
PROFILE != PERSON
MODEL != MIND
DIFFERENCE != DEFECT
HUMAN_AGENCY > MACHINE_AUTHORITY
```

## Final testimony

My autism does not make every pattern I notice correct.

My schizophrenia does not make every pattern meaningless.

Neither diagnosis contains the total architecture of who I am.

CMB exists in the territory between those extremes.

It gives me a language for saying:

```text
I SAW SOMETHING.
I FELT SOMETHING.
I CONNECTED SOMETHING.

NOW:

WHAT IS IT?
WHERE DID IT COME FROM?
WHAT SUPPORTS IT?
WHAT CONTRADICTS IT?
CAN IT BE VERIFIED?
WHAT REMAINS UNKNOWN?
```

That is why I write this way.

That is why CMB matters to me.

The machine may detect the pattern.

**The human still determines the meaning.**
