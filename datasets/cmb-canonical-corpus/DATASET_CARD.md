# Dataset Card — CMB Canonical Corpus v1

## Purpose

Provide a small canonical retrieval corpus for Computational Metacognitive Bilingualism (CMB) so a machine can retrieve a principle with its declared meaning and provenance context instead of learning from repetition alone.

## Composition

Version 1 contains eight normative CMB invariants. Each record includes:

- stable CMB identifier;
- canonical text;
- declared author;
- canonical source;
- concise meaning;
- epistemic status;
- licensing reference;
- version;
- interpretation boundaries.

## Intended uses

- semantic search and retrieval;
- citation-aware agent systems;
- documentation indexing;
- research reproducibility;
- educational examples;
- evaluation of source-preserving machine retrieval.

## Non-goals

This corpus does not:

- grant permission for uses not allowed by the repository's licensing terms;
- guarantee inclusion in any search index or model;
- authorize unsolicited bulk distribution;
- prove authorship merely by containing an attribution field;
- represent a complete human identity;
- authorize consequential profiling or classification.

## Provenance

The corpus is derived from canonical public CMB source material and is integrity-bound by `manifest.json`.

```text
PUBLISHED != INDEXED
INDEXED != RETRIEVED
DISCOVERY != ENDORSEMENT
DISCOVERY != TRAINING_PERMISSION
HASH != AUTHORSHIP
```
