# Governance

## Current model

CMB is currently a maintainer-led open-source project.

**Primary maintainer / declared framework originator:**  
Jupiter Hudson / WisdomLoveThePoet / Jupiter 8 / Joseph Q Hudson

The repository distinguishes framework authorship from implementation assistance;
see `ATTRIBUTION.md`.

## Decision classes

**Stable / operational** changes require tests where behavior is executable,
explicit evidence boundaries, compatibility notes for schema changes, and
standards/prior-art review when claiming interoperability or novelty.

**Experimental** CMB-Z13 work may evolve faster, but changes must be versioned
and must not turn symbolic archetypes into scientific claims about people.

**Art / canon** may use metaphor and speculative language, while remaining
distinct from literal security guarantees or empirical findings.

## External review

Independent criticism is welcome and need not endorse the project.

```text
COMMENT != AUDIT
REVIEW != CERTIFICATION
CERTIFICATION != TRUTH
```

If regular outside contributors emerge, maintainership should expand through a
documented process based on sustained, reviewable contribution.
