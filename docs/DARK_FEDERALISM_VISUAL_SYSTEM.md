This document defines the repository's optional **Dark Federalism / Apocalyptic Archive** presentation layer. It is a visual and literary system, not a claim that an apocalypse, prophecy, omen, or prediction is factually occurring.

## Master aesthetic

The visual language combines a federal archive, redacted intelligence dossier, terminal interface, analog-horror warning system, damaged research manuscript, and digital-glitch field. The purpose is productive unease: the reader should feel that the archive contains an urgent question worth investigating, while the underlying research remains legible and falsifiable.

## Typography contract

GitHub Markdown cannot globally replace GitHub's interface fonts or inject arbitrary CSS. Therefore the repository uses typography through SVG artwork, headings, monospace blocks, Unicode-safe symbols, and image assets rather than pretending the GitHub UI itself can be reskinned.

- **Display:** condensed distressed serif/sans appearance inside SVG artwork.
- **Research prose:** GitHub's native readable font stack.
- **Machine layer:** monospace.
- **Warnings:** uppercase, short, high contrast.
- **Prophecy:** serif/archival treatment, always paired with an epistemic boundary.

Accessibility outranks atmosphere: no critical distinction may depend on color alone; all decorative images need alt text; body copy remains high contrast; flashing animation is prohibited.

## Image-decoration protocol

Photographs and generated artwork should not be dumped into one wall. Each image gets a semantic job and a stable repository path:

```text
assets/visual-system/
├── 00-master/       # repository gateway / hero
├── 10-truth/        # search, evidence, question mark
├── 20-prophecy/     # D.N.A. Bible / 2030 symbolic works
├── 30-anomaly/      # MissingNo / unknown / Recovery
├── 40-human/        # agency / cognition / authorship
├── 50-machine/      # computation / infrastructure
├── 60-symbiosis/    # human-machine co-evolution
└── 90-archive/      # decorative fragments / historical material
```

Every image placement should include: descriptive alt text, source/provenance when known, whether it is documentary or illustrative, and a link to the relevant canonical text. Decorative imagery must never be presented as evidence for a factual claim.
