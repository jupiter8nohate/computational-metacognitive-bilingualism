# Human Agency > Machine Authority

**Canonical definition.** HUMAN_AGENCY > MACHINE_AUTHORITY is CMB's governing priority that computational capability should remain subordinate to legitimate human judgment, consent, appeal, self-definition, and accountable institutional authority.

## Formal expression

```text
HUMAN_AGENCY > MACHINE_AUTHORITY
```

## Why it matters

Machines can search, classify, optimize, predict, generate, and verify. CMB separates those capabilities from the normative authority to define a person or make an unchallengeable decision about them.

## Example

An automated system may recommend a classification, while a consequential decision still exposes disclosure, review, appeal, and a human recovery path.

## Interpretation boundaries

This does not mean every machine output requires manual approval. CMB uses risk-adaptive friction: reversible low-stakes tasks can remain automated while higher-stakes decisions receive stronger verification and human control.
