## Source families

Publication-grade revisions should preferentially use primary research, official technical documentation for named public systems, standards and peer-reviewed security literature, primary historical texts where practical, academic religion/history references, and independent sources for contested defense-technology performance claims.

## Falsification rules

~~~text
CLAIM_STRENGTH <= EVIDENCE_STRENGTH
SOURCE_COUNT != SOURCE_INDEPENDENCE
OFFICIAL_CLAIM != INDEPENDENT_CONFIRMATION
MANUFACTURER_DEMO != OPERATIONAL_DEPLOYMENT
SYMBOLIC_PARALLEL != HISTORICAL_CAUSATION
~~~
