# CMB Case Studies

This directory records concrete examples used to test CMB claims against observable systems.

Case studies are evidence logs, not mythology. Each one should separate:

- observed output;
- direct evidence;
- inference;
- unsupported claims;
- alternative explanations;
- falsification criteria;
- revision conditions.
