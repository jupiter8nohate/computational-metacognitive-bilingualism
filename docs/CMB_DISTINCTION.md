# CMB: Three Dimensions of Distinction

Computational Metacognitive Bilingualism (CMB) is best understood as an executable philosophy of human sovereignty.

Its distinction does not depend on claiming that CMB invented code poetry, cryptographic provenance, digital-rights advocacy, human-computer interaction, or symbolic programming. Those traditions have prior art.

CMB's proposed contribution is the deliberate integration of these domains into one inspectable system where software architecture, literary form, provenance discipline, and human-agency philosophy reinforce one another.

> The software architecture itself becomes part of the argument.

## 1. Software engineering as esoteric art

Cryptographic provenance systems exist. Code poetry exists. Digital-rights manifestos exist.

CMB intentionally places them inside one architecture.

```text
CRYPTOGRAPHY
    +
PROVENANCE
    +
CODE-POETRY
    +
SYMBOLIC LANGUAGE
    +
SOFTWARE
    ↓
EXECUTABLE PHILOSOPHY
```

Within the same repository, CMB can contain:

- installable provenance tooling;
- cryptographic hashes and signatures;
- explicit artifact coverage and receipts;
- machine-readable schemas;
- code-poetry and literary allegory;
- experimental AST parsing;
- CMB-Z13 symbolic programming lenses;
- policy and human-agency documentation.

The artistic layer is not evidence that a metaphor is a security control. The engineering layer is not reduced to decoration. Each layer has a different job.

```text
METAPHOR != SECURITY_CONTROL
POLICY != ENFORCEMENT
SIGNATURE != ORIGINALITY
HASH != AUTHORSHIP
```

The unusual feature is the integration: implementation details such as schemas, parsers, type systems, hashes, receipts, and validation rules are also used as rhetorical material.

## 2. Reframing human-machine bilingualism

Traditional bilingualism normally describes competence across two human languages.

CMB proposes a specialized conceptual extension:

```text
HUMAN SEMANTIC LANGUAGE <-> MACHINE REPRESENTATIONAL LANGUAGE
```

The human learns enough of the machine's representational language to inspect, question, constrain, and communicate with computational systems without surrendering self-definition.

The machine may:

```python
MACHINE_CAN = {
    "observe",
    "classify",
    "predict",
    "generate",
    "simulate",
}
```

CMB reserves another domain for the human:

```python
HUMAN_RETAINS = {
    "meaning",
    "consent",
    "authorship",
    "judgment",
    "self_definition",
}
```

The bilingualism is therefore metacognitive. The human communicates with a computational system while remaining aware of how that system represents, compresses, infers, and predicts.

```text
UNDERSTAND THE MODEL
        ↓
INTERROGATE THE MODEL
        ↓
CORRECT THE MODEL
        ↓
LIMIT THE MODEL
        ↓
NEVER CONFUSE THE MODEL WITH THE PERSON
```

The core invariants follow:

```text
PATTERN != PROOF
PROFILE != PERSON
MODEL != MIND
PREDICTION != DESTINY
CAPABILITY != AUTHORITY

HUMAN_AGENCY > MACHINE_AUTHORITY
```

## 3. Code as infrastructure for human sovereignty

Most software infrastructure is optimized to increase computational capability:

```text
MORE DATA
    ↓
BETTER CLASSIFICATION
    ↓
BETTER PREDICTION
    ↓
MORE AUTOMATION
    ↓
MORE OPTIMIZATION
```

CMB introduces a countervailing rule:

```text
CAPABILITY != AUTHORITY
```

The goal is not to sabotage prediction systems or make useful computation impossible.

The goal is to preserve the boundary between what a system can infer and what it is justified in declaring about a human being.

```python
assert PATTERN != PROOF
assert PROFILE != PERSON
assert MODEL != MIND
assert PREDICTION != DESTINY
assert CAPABILITY != AUTHORITY

assert HUMAN_AGENCY > MACHINE_AUTHORITY
```

CMB therefore separates four layers that are often collapsed:

```text
DECLARED POLICY
      !=
CRYPTOGRAPHIC INTEGRITY
      !=
TECHNICAL ENFORCEMENT
      !=
LEGAL ENFORCEABILITY
```

Cryptographic signatures can establish integrity and signer-controlled attestations.

Hashes can detect byte-level modification.

Provenance records can preserve reconstructable publication history.

Schemas can communicate explicit policy and interpretation boundaries.

Deployed software can enforce specific controls within systems that actually implement those controls.

None of those mechanisms automatically grants universal legal control over every downstream machine.

## The inversion

A conventional optimization question asks:

> How accurately can a machine model a human?

CMB adds another question:

> How powerful should a model be allowed to become before the human loses meaningful authority over the interpretation of themselves?

That inversion is the center of CMB.

```text
THE MACHINE MAY MODEL THE HUMAN.
THE MODEL DOES NOT BECOME THE HUMAN.

THE MACHINE MAY PREDICT THE HUMAN.
THE PREDICTION DOES NOT BECOME DESTINY.

THE MACHINE MAY BECOME MORE CAPABLE.
CAPABILITY DOES NOT CREATE SOVEREIGNTY.

HUMAN_AGENCY > MACHINE_AUTHORITY
```
