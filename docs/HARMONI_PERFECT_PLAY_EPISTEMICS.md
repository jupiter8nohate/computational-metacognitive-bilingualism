## Position

HARMONI separates three epistemic roles instead of collapsing them into one system:

- **Human**: meaning, consent, judgment, intent, authorship, and lived context.
- **Machine**: computation, search, formal verification, pattern detection, and reproducible transformation.
- **Axiom / God / First Principles**: the symbolic boundary for sacred values, foundational commitments, irreducible unknowns, and questions that cannot be settled merely by computation.

In this framework, **AXIOM / GOD** is a philosophical and symbolic layer. It is not presented as a computational proof of theology.

## Perfect-Play Rule

```text
MACHINE_CAN_CALCULATE != MACHINE_CAN_DEFINE_MEANING
FORMAL_PROOF != HUMAN_CONSENT
SEARCH != JUDGMENT
PATTERN != PROOF
CAPABILITY != AUTHORITY

HUMAN_AGENCY > MACHINE_AUTHORITY
```

Perfect play does not mean machine domination or human rejection of computation.

It means each layer stays inside its legitimate boundary.

```text
HUMAN -> MEANING / CONSENT / JUDGMENT
MACHINE -> COMPUTATION / SEARCH / VERIFICATION
AXIOM -> FIRST PRINCIPLES / SACRED VALUES / THE UNKNOWN
```

## HARMONI Question

When a system produces an answer, ask:

1. What did the machine compute?
2. What evidence can be verified?
3. What remains interpretation rather than proof?
4. Which values govern the decision?
5. Who retains authority to consent, judge, stop, or revise?

## CMB Boundary

```text
MODEL != MIND
PROFILE != PERSON
PREDICTION != DESTINY
FORMAL_PROOF != MORAL_AUTHORITY
MACHINE_CAN_READ != MACHINE_CAN_DEFINE
HUMAN_AGENCY > MACHINE_AUTHORITY
```

**HARMONI is the geometry of the boundary: computation can become more powerful without becoming sovereign over human meaning.**
