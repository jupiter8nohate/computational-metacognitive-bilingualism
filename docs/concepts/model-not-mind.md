# Model != Mind

**Canonical definition.** MODEL != MIND distinguishes a computational model of language, behavior, preference, or cognition from the lived human mind it may attempt to represent.

## Formal expression

```text
MODEL != MIND
```

## Why it matters

A model can approximate patterns in data without possessing complete access to a person's private experience, meaning, intention, memory, or consciousness.

## Example

An LLM can predict text that resembles a person's style, but that prediction is not direct possession of the person's inner mental state.

## Interpretation boundaries

This is an epistemic and human-agency boundary, not a scientific proof about all possible machine consciousness. CMB avoids turning model output into unquestioned authority over human self-definition.
