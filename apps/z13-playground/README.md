# CMB-Z13 Playground

A zero-build static web playground for the thirteen CMB-Z13 Guardian Modes.

Open `index.html` locally or serve this directory with any static HTTP server.

The playground deliberately keeps the execution model simple:

- no analytics;
- no account;
- no network requests;
- no model API;
- no psychological inference;
- no zodiac personality classification;
- deterministic transformation from user text to symbolic computational lenses.

Views:

- **Human** — plain-language interpretation;
- **Machine** — machine-readable invariant form;
- **Flamingoglyph** — artistic CMB/FGC presentation.

The zodiac-language mappings are a symbolic design system, not scientific claims about personality or cognition.
