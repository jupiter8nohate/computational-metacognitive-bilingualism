# CMB-CAP A2A Extension v1

## Identifier

```text
https://jupiter8nohate.github.io/computational-metacognitive-bilingualism/extensions/cmb-cap/v1
```

## Status

Experimental CMB extension profile for Agent2Agent (A2A) transports.

It is not an official A2A extension and does not claim A2A conformance.

## AgentExtension declaration

```json
{
  "uri": "https://jupiter8nohate.github.io/computational-metacognitive-bilingualism/extensions/cmb-cap/v1",
  "description": "Carries CMB-CAP signed human-to-agent authority credentials.",
  "required": false,
  "params": {
    "protocol": "CMB-CAP-1",
    "schema": "cmb.capability-credential.v1"
  }
}
```

The extension is data-only and SHOULD remain optional unless an integrating
agent explicitly requires CMB-CAP authorization for a defined operation.

## Payload

A message or artifact using this extension may carry:

```json
{
  "extension_uri": "https://jupiter8nohate.github.io/computational-metacognitive-bilingualism/extensions/cmb-cap/v1",
  "protocol": "CMB-CAP-1",
  "credential_digest": "sha256:<64 hex>",
  "credential": {
    "schema": "cmb.capability-credential.v1"
  }
}
```

The complete `credential` object MUST validate under the CMB-CAP runtime
verifier. The abbreviated object above illustrates placement only.

## Processing

An integrating agent SHOULD:

1. recognize the extension URI;
2. verify the credential signature;
3. enforce expiry;
4. pin or resolve the issuer key when trusted identity matters;
5. verify parent lineage when present;
6. evaluate the embedded CMB-SDL authority before executing the requested action;
7. fail closed when the credential is malformed or outside scope.

```text
EXTENSION_SUPPORT != AUTHORIZATION
VALID_SIGNATURE != TRUSTED_IDENTITY
CREDENTIAL != ENFORCEMENT
```
