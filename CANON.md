## Evidence boundary

The canon intentionally separates declaration, integrity, enforcement, and law.

```text
DECLARATION != PROOF
HASH != AUTHORSHIP
SIGNATURE != COPYRIGHT
TIMESTAMP != TRUTH
PROVENANCE != LEGAL_JUDGMENT
```

Cryptographic evidence can strengthen a provenance record. It cannot, by itself, prove ownership, originality, mental state, or legal entitlement.

## MissingNo clause

```text
UNCLASSIFIED != NONEXISTENT
UNKNOWN != INVALID
INDEX != IDENTITY
CLASSIFY != KNOW
PREDICT != DETERMINE
```

When a person does not fit a schema, CMB treats that as a reason to inspect the model before correcting the person.

## Repository truthfulness

The machine graph includes `unlinked` nodes for parts of the broader creative system that do not yet have a canonical artifact in this repository. An unlinked node is a declared integration target, not evidence that a file, compiler, book, or release already exists here.

That distinction is deliberate:

```text
CANONICAL_PATH = PRESENT_AND_RESOLVABLE
UNLINKED_NODE = DECLARED_BUT_NOT_YET_ATTACHED
```
