# CMB-EDU Kids // Flamingoglyph Learning Layer

> Speak Computer. Speak Human. Never forget which one you are.

CMB-EDU is an experimental educational layer for teaching children computational literacy, metacognition, privacy, consent, verification, and creative human-machine collaboration.

It represents **human-declared interaction context**, not psychological truth or diagnosis.

```text
PATTERN != PROOF
PROFILE != PERSON
MODEL != MIND
PREDICTION != DESTINY
DIFFERENCE != DEFECT
FEELING_NOW != IDENTITY_FOREVER
HUMAN_AGENCY > MACHINE_AUTHORITY
```

## The five-step thinking game

```text
👁️ NOTICE -> ❓ QUESTION -> 🔍 VERIFY -> 🧠 DECIDE -> 🎨 CREATE
```

If an AI homework helper gives an answer, a student does not have to copy it. The student can ask why, check another trustworthy source, understand the result, and then decide whether to use it.

```text
AI_CAN_BE_WRONG = TRUE
HUMAN_CAN_VERIFY = TRUE
```

## Everyday lessons

### Recommendations

A video service may notice repeated dinosaur videos. That is a pattern, not a complete identity.

```text
WATCHING != IDENTITY
PROFILE != PERSON
```

### Online privacy

If someone online asks for private information:

```text
🔒 PRIVATE -> 🚫 DO_NOT_SHARE -> 🧑 ASK_TRUSTED_ADULT
```

```text
INTERNET_REQUEST != OBLIGATION
CAN_SHARE != SHOULD_SHARE
```

### Machine guesses about feelings

If a system says, “You seem angry,” the child may correct it. CMB-EDU records the child's declaration as a declaration rather than silently turning it into a permanent psychological profile.

```text
MACHINE_INFERENCE != HUMAN_SELF_DEFINITION
FEELING_NOW != IDENTITY_FOREVER
```

## Dual-Brain Stream

Example:

```text
♌::CREATIVE -> STATE[confident || overstimulated] => GENERATE("dragon_story") -> PROFILE_NOT_PERSON;
```

The reference parser emits a `cmb.edu.v1` Metacognitive Context Envelope. Context is explicitly marked `human_declared`, `machine_inferred=false`, and `current_interaction`.

Privacy defaults are deliberately restrictive:

```text
PERSISTENCE = EPHEMERAL
TRAINING_PERMISSION = FALSE
PROFILING_PERMISSION = FALSE
SECONDARY_USE_PERMISSION = FALSE
PSYCHOLOGICAL_INFERENCE_PERMISSION = FALSE
```

These fields express CMB policy semantics. They do not magically force an external service to comply; real deployments must implement enforcement, access control, retention controls, consent processes, and applicable child-privacy requirements.

## Engineering boundary

CMB-EDU is experimental educational software and symbolic language design. It is not a diagnostic system, medical device, identity verifier, psychological assessment, or proof that future AGI/ASI systems will prefer CMB-formatted input.

Its narrower technical goal is testable: provide a structured representation for declared context, instruction, sovereignty boundaries, and privacy defaults while keeping human declarations distinct from machine inference.
