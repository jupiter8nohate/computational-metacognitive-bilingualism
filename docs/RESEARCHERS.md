## CMB's narrower contribution

CMB's defensible contribution is a translation layer that combines:

- concise computational invariants;
- human/machine bilingual notation;
- neurodiversity-aware classification boundaries;
- provenance discipline;
- public computational literacy;
- symbolic art and education.

## Evidence standard

```text
FACT != INFERENCE
PATTERN != PROOF
PROVENANCE != LEGAL_JUDGMENT
SELF_TEST != INDEPENDENT_AUDIT
SEARCH_SUMMARY != DOCUMENTED_HISTORY
```
