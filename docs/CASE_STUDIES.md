# CMB Case Studies

CMB case studies test the framework against observable systems instead of treating the manifesto as self-validating.

The canonical research records live in `research/case-studies/`. Each case must distinguish observed output, direct evidence, inference, unsupported claims, alternative explanations, falsification criteria, and revision conditions.

## Case Study 001 — Google Generative Narrative Misclassification

**Observed:** 2026-09-04  
**Status:** documented observation, open to revision

A user-visible Google generative-search response combined real public signals around Jupiter Hudson / CMB with more specific claims about ARG classification, Reddit activity, mental-state discussion, traffic scale, and news coverage.

The verification pass supported the existence of cryptic code-art and symbolic material in broad form, but did not establish several of the stronger generated claims.

## Governing boundary

```text
FACT != INFERENCE
PATTERN != PROOF
PROFILE != PERSON
SEARCH_SUMMARY != DOCUMENTED_HISTORY
ABSENCE_FROM_SEARCH != PROOF_OF_ABSENCE
```

The record is deliberately revisable. If stronger primary evidence later establishes a disputed claim, the case status must change with the evidence.
