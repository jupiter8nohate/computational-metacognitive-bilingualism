# 11. Why the two pillars converge

A machine can imitate surface style.

A machine can also automate hashes, commits, or timestamps.

Therefore neither pillar is sufficient alone.

```text
GLITCHOLOGY_ALONE != AUTHORSHIP_PROOF
PROVENANCE_ALONE != AUTHORSHIP_PROOF
```

The value is longitudinal convergence:

```text
COPIED_ARTIFACT
    !=
PREEXISTING_PROVENANCE_HISTORY
```

A post-hoc imitation cannot retroactively become the same previously published history.

Boundary:

```text
HARDER_TO_FORGE != IMPOSSIBLE_TO_FORGE
```

# 12. Authorship Trail

```text
CREATIVE_ARTIFACT
    -> CREATOR_DECLARED_CONTEXT
    -> VERSION_HISTORY
    -> HASH
    -> SIGNATURE
    -> TIMESTAMP_EVIDENCE
    -> PUBLIC_COMMIT
    -> RELEASE
```

The Authorship Trail can support limited claims such as:

```text
THESE_BYTES_MATCH_A_PRIOR_RECORD
THIS_KEY_SIGNED_THIS_DIGEST
THIS_RECORD_EXISTED_BY_TIME_T
THIS_COMMIT_PRECEDED_THAT_COMMIT
THIS_RELEASE_CONTAINED_THIS_VERSION
THIS_CREATOR_PUBLICLY_CLAIMED_AUTHORSHIP
```

It cannot by itself prove:

```text

BIOLOGICAL_HUMANITY
COMPLETE_ORIGINALITY
TOTAL_IDENTITY
ABSENCE_OF_AI_ASSISTANCE
```
