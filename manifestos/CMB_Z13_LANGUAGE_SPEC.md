## 1. Purpose

CMB-Z13 maps thirteen zodiac archetypes to thirteen software languages and thirteen computational functions. The goal is not to classify human beings by birth date. The goal is to give humans and machines a compact shared vocabulary for moving between structure, innovation, meaning, action, stability, translation, context, expression, verification, balance, inference, metacognition, and exploration.

The system treats every sign as a **computational lens** that a human may invoke when useful.

```text
ZODIAC_SYMBOL != HUMAN_IDENTITY
LANGUAGE != INTELLIGENCE
ARCHETYPE != PERSON
STATISTIC != DESTINY
```

## 4. Native notation

A basic CMB-Z13 expression follows this grammar:

```text
GLYPH :: LANGUAGE -> OPERATOR[TARGET] => RESULT;
```

Examples:

```text
♍::GO -> VERIFY[claim] => EVIDENCE_REQUIRED;
♊::TYPESCRIPT -> TRANSLATE[human_meaning] => machine_representation;
♏::PROLOG -> INFER[pattern] => HYPOTHESIS;
⛎::LISP -> INSPECT[rule] => META(rule);
♈::CPP -> REQUEST[action] => HUMAN_CONSENT_REQUIRED;
```

The constitutional core is:

```text
@CORE {
    PATTERN      != PROOF;

    MODEL        != MIND;
    PREDICTION   != DESTINY;
```
