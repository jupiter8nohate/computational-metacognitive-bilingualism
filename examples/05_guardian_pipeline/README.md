# Example 05 — Guardian safety pipeline

The Guardian Modes are teaching aliases over the canonical CMB-Z13 operators.

```text
♏ Prolog      -> INFER       -> HYPOTHESIS
♍ Go          -> VERIFY      -> EVIDENCE_REQUIRED
♋ Python      -> ADD_CONTEXT -> HUMAN_CONTEXT
♊ TypeScript  -> TRANSLATE   -> EXPLAINABLE_OUTPUT
♎ Kotlin      -> AUDIT       -> FAIRNESS_CHECK
⛎ Common Lisp -> INSPECT     -> META_REVIEW
♈ C++         -> REQUEST     -> HUMAN_AUTHORIZATION_REQUIRED
Human         -> DECIDE      -> HUMAN_DECISION
```

The sequence is an explanatory reasoning model, not an autonomous decision
engine.
