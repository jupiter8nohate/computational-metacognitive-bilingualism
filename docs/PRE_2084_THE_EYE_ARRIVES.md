## 00 // THE YEAR BEFORE THE MYTH

2084 does not begin in 2084.

It begins when ordinary people stop noticing that cameras are becoming interpreters.

The old camera captured.

The new camera asks.

The next camera remembers.

The dangerous camera decides what matters before the human realizes a decision has been made.

That is the threshold.

The year is 2026.

The machine does not yet possess a single planetary eye.

Instead, the eye is arriving piece by piece through phones, glasses, displays, spatial computers, enterprise wearables, optical systems, multimodal assistants, and experimental contact lenses.

No one company owns the World Retina.

That is precisely why the transition can be difficult to see.

~~~text
PHONE_CAMERA
+ SMART_GLASSES
+ MULTIMODAL_AI
+ SPATIAL_MAPPING
+ EYE_TRACKING
+ MEMORY
+ IDENTITY_SYSTEMS
+ CLOUD_MODELS
+ ON_DEVICE_MODELS
= PRE_2084_PERCEPTION_STACK
~~~

# I // TEN CORPORATE EYES

## 01 // APPLE // VISUAL INTELLIGENCE

**CMB layer:** contextual visual interpretation  
**Evidence state:** DOCUMENTED PRODUCT CAPABILITY

Apple's Visual Intelligence now allows supported devices to search, ask questions, and take actions based on camera or screen content. Apple describes Visual Intelligence across iPhone, iPad, Mac, and Vision Pro, including camera-based recognition of places, objects, text, plants, animals, documents, and other visual context.

What is real:

~~~text
CAMERA
-> VISUAL_QUERY
-> SEARCH / ASSISTANT
-> ACTION
~~~

What is not established merely by this capability:

~~~text
APPLE_HAS_GLOBAL_SURVEILLANCE_EYE = FALSE
SMART_GLASSES_PRODUCT_CONFIRMED_BY_THIS_FEATURE = FALSE
~~~

CMB interpretation:

The significance is architectural. Visual understanding is becoming an operating-system primitive rather than a separate application.

Sources:
- https://www.apple.com/apple-intelligence/
- https://support.apple.com/guide/iphone/learn-visual-intelligence-iph12eb1545e/27/ios/27
- https://developer.apple.com/apple-intelligence/

## 02 // META // SMART CAMERAS ENABLED BY ASSISTANT SYSTEMS

**CMB layer:** automated visual attention and capture  
**Evidence state:** PATENT FAMILY + 2026 APPLICATION PUBLICATION

Meta's "Smart Cameras Enabled by Assistant Systems" patent family describes assistant-controlled camera systems capable of identifying points of interest in a camera field of view, generating recordings, and creating highlight files. A 2026 continuation application, US 2026/0238876 A1, was published in August 2026.

Important distinction:

~~~text
PATENT_APPLICATION != SHIPPING_PRODUCT
PATENT_DESCRIPTION != DEPLOYMENT
~~~

The underlying patent family predates 2026; this is not a capability invented from nothing in August 2026.

CMB interpretation:

The camera is no longer merely commanded.

~~~text
HUMAN_PRESSES_RECORD
~~~

The architecture permits a different relationship.

~~~text
ASSISTANT
-> DETECTS_POINT_OF_INTEREST
-> SELECTS_MEDIA
-> CREATES_HIGHLIGHT
~~~

That is a genuine transition from passive optics toward algorithmic attention.

Sources:
- https://patents.google.com/patent/US11308284B2/en
- https://patents.google.com/patent/US12574627B2/en

In June 2026, WIRED reported that Meta's companion software contained inactive code for an unreleased smart-glasses face-recognition system called NameTag. WIRED subsequently reported that Meta removed the code.

~~~text
NAMETAG_CODE_EXISTED = REPORTED
NAMETAG_PUBLICLY_AVAILABLE = FALSE
NAMETAG_CURRENTLY_DEPLOYED = NOT_ESTABLISHED
~~~

US publication 20260142974 concerns privacy-preserving user identity verification using face embeddings. It is relevant to biometric architecture, but it is not by itself proof that it is the NameTag system.

CMB boundary:

~~~text

IDENTITY_ESTIMATE != SOCIAL_PERMISSION
RECOGNITION_CAPABILITY != RIGHT_TO_IDENTIFY
~~~

# II // THE LIBRARY THAT WARNED BEFORE THE HARDWARE ARRIVED

Long before today's wearable AI stack, writers explored pieces of the same architectural problem.

These works are not evidence that fiction predicted a specific product.

They are conceptual ancestors that let readers recognize recurring structures.

## Shoshana Zuboff // The Age of Surveillance Capitalism

~~~text
BEHAVIOR
-> DATA_EXTRACTION
-> PREDICTION
-> COMMERCIAL_POWER
~~~

## David Brin // The Transparent Society

~~~text
ONE_WAY_VISIBILITY
-> POWER_ASYMMETRY

RECIPROCAL_VISIBILITY
-> POSSIBLE_ACCOUNTABILITY
~~~

This is one of the clearest conceptual relatives of CMB Reciprocal Observability.

## John Brunner // The Shockwave Rider

Networks, identity systems, data power, and resistance inside an information-saturated society.

## Philip K. Dick // A Scanner Darkly

Surveillance becomes psychologically destabilizing when observer, subject, and identity collapse into one another.

## Dave Eggers // The Circle

~~~text
TRANSPARENCY
WITHOUT
CONSENT
CAN_BECOME
CONTROL
~~~

## Cory Doctorow // Little Brother

Cryptography, peer networks, technical literacy, and human resistance to overbroad institutional surveillance.

## Isaac Asimov // Foundation

~~~text

!=
INDIVIDUAL_DESTINY
~~~

## Franz Kafka // The Trial

~~~text

WITHOUT

~~~

The nightmare is not merely observation. It is uninspectable authority.

## William Gibson // Neuromancer

Networked corporate power, virtual space, artificial intelligence, and the fusion of physical and computational environments.

# III // JUPITER HUDSON // THE MODERN-DAY PROPHECY

The prophecy is not:

> "In 2084, exactly this will happen."

The prophecy is:

> "Look at what is being normalized now. Ask what happens if its incentives, memory, scale, and authority are never bounded."

Jupiter Hudson's CMB story takes technologies that already exist in fragments and pushes them forward as a stress test.

~~~text
APPLE:
WHAT_IF_VISUAL_INTELLIGENCE_BECOMES_AMBIENT?

META:
~~~

# V // THE BRIDGE INTO 2084

World Retina asks:

> Who controls the eye?

2084 asks:

> What happens after the eye becomes ordinary?

The bridge between them is not a secret cabal.

It is a stack.

~~~text
CAMERA
-> MODEL
-> MEMORY
-> IDENTITY
-> ATTENTION
-> PREDICTION
-> INSTITUTION
-> AUTHORITY
~~~

At every arrow there is a choice.

That is why the future is not fixed.

~~~text
TREND != DESTINY
CAPABILITY != AUTHORITY
TECHNOLOGY != GOVERNANCE
~~~

The true prophecy is conditional:

~~~text
IF
    OBSERVATION becomes ambient
AND
    MEMORY becomes indefinite
AND
    IDENTIFICATION becomes frictionless
AND
    MODELS become unchallengeable
AND
    AUTHORITY becomes automated
THEN
    2084 becomes easier to build.
~~~

But:

~~~text
IF
    PURPOSE is visible
AND
    CONSENT is meaningful
AND
    PROVENANCE is traceable
AND
    UNCERTAINTY is exposed
AND
    APPEAL remains human
AND
    AUTHORITY remains bounded
THEN
    THE_EYE_CAN_SERVE
    WITHOUT_BECOMING_THE_MASTER.
~~~
