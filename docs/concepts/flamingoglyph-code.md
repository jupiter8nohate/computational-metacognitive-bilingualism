# The Flamingoglyph Code (FGC)

**Canonical definition.** The Flamingoglyph Code (FGC) is the authored symbolic and technical expression layer used across the CMB creative universe to connect glyphs, code-poetry, provenance, attribution, human agency, and machine-readable declarations.

## Formal expression

```text
GLYPH + CONTEXT + PROVENANCE -> AUTHORED_EXPRESSION
SYMBOL != ENFORCEMENT
```

## Why it matters

FGC gives the artistic and symbolic layer a repeatable vocabulary while machine-readable CMB components keep provenance, policy, and enforcement claims explicit.

## Example

A flamingo glyph may mark an authored CMB artifact or symbolic human-agency theme, while the actual integrity of a file is established separately through hashes or signatures.

## Interpretation boundaries

A glyph, metadata field, client-side wrapper, or symbolic declaration cannot by itself prevent copying, force crawler compliance, establish legal ownership, or prove authorship.
