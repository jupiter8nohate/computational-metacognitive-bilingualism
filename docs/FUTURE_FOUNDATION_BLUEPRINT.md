# Future Foundation Blueprint

**Current status:** design laboratory only — not a legal organization.

The repository is intentionally learning how CMB / Err ⃝or⃟⃤ GLITCHOLOGY should be governed before forming a nonprofit, trust, foundation, treasury, or fundraising program.

Nothing in the blueprint creates:

- a corporation;
- a charitable trust;
- a board with legal authority;
- 501(c)(3) status;
- tax-deductible donation rights;
- a fiduciary relationship;
- an intellectual-property transfer.

~~~text
DRAFT != ADOPTED
BLUEPRINT != LEGAL_ENTITY
PUBLIC_STEWARDSHIP != TAX_EXEMPT_STATUS
~~~

## Formation trigger

The project should consider legal formation only after it can answer, with evidence from actual operating history:

1. What mission needs to be legally locked?
2. Which assets and IP, if any, should enter stewardship?
3. What decisions need independent governance?
4. What activities truly require money?
5. What accounting and compliance burden can be sustained?
6. How should conflicts, succession, removal, and dissolution work?
7. Is public fundraising actually necessary?
