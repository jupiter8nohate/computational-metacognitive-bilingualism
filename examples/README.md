# CMB Examples

These examples are deliberately small. Each one demonstrates one idea without
requiring the reader to understand the entire CMB canon.

1. `01_seal_a_file/` — create an explicit provenance receipt.
2. `02_verify_a_receipt/` — verify bytes against a receipt.
3. `03_c2pa_roundtrip/` — understand the CMB → C2PA integration boundary.
4. `04_z13_verify_claim/` — parse one CMB-Z13 verification statement.
5. `05_guardian_pipeline/` — read the multi-lens human-decision sequence.
