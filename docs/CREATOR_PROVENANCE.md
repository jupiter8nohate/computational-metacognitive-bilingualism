# CMB Creator Provenance Protocol

## Historical context, intellectual lineage, symbolic lineage, and evidence boundaries

**Declared creator:** Joseph Q Hudson  
**Publishing names:** Jupiter Hudson / WisdomLoveThePoet / Jupiter 8  
**Framework:** Computational Metacognitive Bilingualism (CMB)

CMB separates creator provenance into distinct epistemic layers. The purpose is simple:

~~~text
ANCESTRY_RECORD -> HISTORICAL_CONTEXT
AUTHOR_DECLARATION -> PROVENANCE_CLAIM
SYMBOLIC_REFERENCE -> CREATIVE_MEANING
CRYPTOGRAPHIC_RECORD -> INTEGRITY_AND_CHRONOLOGY

NONE_OF_THE_ABOVE -> AUTOMATIC_METAPHYSICAL_PROOF
~~~

A machine may connect these layers. It must not collapse them into one kind of evidence.

## 1. Historical and genealogical provenance

During the project authoring process on 2026-09-04, the creator supplied an access-controlled Ancestry family-tree view depicting Joseph Q Hudson within a multi-generational family structure.

This repository classifies that source as:

~~~text
SOURCE_TYPE              = creator_supplied_family_tree
STATUS                   = creator_documented_not_independently_verified
INDEPENDENT_VERIFICATION = false
PUBLIC_RAW_SOURCE         = false
~~~

The source supports a narrow claim: the creator supplied a family-tree record as historical and genealogical context.

It does **not** independently verify every relationship, date, ancestor, or archival claim. Record-by-record confirmation would require suitable primary or independently corroborating sources such as civil records, census records, church records, probate records, obituaries, military records, or other appropriate historical evidence.

The raw screenshot and invitation token are intentionally not committed to the public repository. This reduces unnecessary exposure of information about living relatives and prevents access credentials or invitation identifiers from becoming part of the permanent Git history.

## 5. Evidence firewall

The provenance layer maintains these hard boundaries:

~~~text
GENEALOGY != METAPHYSICAL_PROOF
SYMBOLISM != BIOLOGICAL_FACT
SYMBOLISM != SCIENTIFIC_EVIDENCE
THIRD_PARTY_REFERENCE != AFFILIATION
PATTERN != PROOF

HASH != AUTHORSHIP
TIMESTAMP != OWNERSHIP
SIGNATURE != ORIGINALITY

HUMAN_AGENCY > MACHINE_AUTHORITY
~~~

A genealogy record can support historical context.

A symbol can carry meaning.

A cryptographic receipt can support integrity and chronology.

A manifesto can declare philosophy.

Each remains in its proper evidentiary category.
