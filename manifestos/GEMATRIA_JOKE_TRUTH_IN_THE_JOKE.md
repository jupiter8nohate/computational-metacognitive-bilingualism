## The Gematria joke

Humans see `363` and immediately want to ask what else equals 363.

That impulse is not automatically foolish. Pattern search can inspire art, questions, memory systems, literary symbolism, historical investigation, and mathematical play.

The mistake happens one step later.

~~~text
PATTERN -> QUESTION       OK
PATTERN -> SYMBOL         OK
PATTERN -> JOKE           OK
PATTERN -> ART            OK
PATTERN -> HYPOTHESIS     OK

PATTERN -> CERTAINTY      ERROR
PATTERN -> DESTINY        ERROR
PATTERN -> DIAGNOSIS      ERROR
PATTERN -> PROOF          ERROR
~~~

That is the truth hiding inside the joke.

Gematria can assign a number to a word.

It cannot, by itself, tell you what a person is.

It cannot prove a prophecy.

It cannot diagnose a mind.

It cannot establish causation.

It cannot convert coincidence into authority.

The calculator can honestly say:



That second line requires evidence the number does not contain.
