# 8. Limitations

The CMB Bio-Silicon Verification Laboratory is intentionally narrow.

## What it can establish

Given a numerical observation vector, a numerical reference vector, and explicit per-channel tolerances, the reference implementation can determine whether every residual falls within the declared bounds.

## What it cannot establish

It does not establish:

- consciousness, sentience, cognition, intent, or personhood;
- that an organoid is equivalent to a human brain;
- that a selected metric captures the full biological state;
- causal mechanisms from correlation alone;
- clinical validity or medical safety;
- universal thresholds for biological interpretation;
- experimental reproducibility without independent replication;
- ethical permission or regulatory authorization.

## Model dependence

A result is only as meaningful as its inputs.

```text
BAD REFERENCE + PRECISE CALCULATION = PRECISELY TESTED BAD REFERENCE
```

A zero or small residual can show internal consistency while the underlying model remains incomplete or inappropriate.

```text
RESIDUAL_ZERO != UNIVERSAL_TRUTH
LOW_ERROR != COMPLETE_MODEL
MODEL_CONSISTENT != REALITY_EXHAUSTED
```

The CMB response to this limitation is not to abandon modeling. It is to attach every result to assumptions, provenance, tolerances, and a bounded claim.
