## Constitutional Core

```text
PATTERN != PROOF
PROFILE != PERSON
MODEL != MIND
PREDICTION != DESTINY
CAPABILITY != AUTHORITY

HUMAN_AGENCY > MACHINE_AUTHORITY
```

CMB-Z13™ is a symbolic human–machine language that maps thirteen zodiac archetypes to thirteen software languages and thirteen computational lenses.

The zodiac layer is symbolic, not deterministic. It does not claim that birth date determines personality, intelligence, identity, destiny, or moral worth.

```text
ZODIAC_SYMBOL != HUMAN_IDENTITY
ARCHETYPE != PERSON
STATISTIC != DESTINY
LANGUAGE != INTELLIGENCE
```
