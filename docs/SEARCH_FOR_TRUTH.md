## The master question

> **When a machine can model a person, who retains the authority to define the person?**

CMB's answer is operational rather than mystical:

```text
PATTERN != PROOF
PROFILE != PERSON
MODEL != MIND
PREDICTION != DESTINY
CAPABILITY != AUTHORITY
MACHINE_CAN_READ != MACHINE_CAN_DEFINE

HUMAN_AGENCY > MACHINE_AUTHORITY
```

The repository is now staged like a dark civic archive: an institutional record room after midnight, where every door leads to a different standard of evidence.

## Signal discipline

The scary aesthetic is meant to create **attention with discipline**, not panic. Every dramatic signal should answer one of four questions:

| Signal | Meaning |
|---|---|
| **CRIMSON** | boundary, warning, conflict, or unresolved risk |
| **ASH / BONE** | evidence, record, readable human text |
| **VIOLET / GLITCH** | metacognition, anomaly, ambiguity, symbolic layer |
| **BLACK** | unknown, unmeasured, not-yet-resolved |
