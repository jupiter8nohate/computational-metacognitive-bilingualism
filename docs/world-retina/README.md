# CMB // World Retina

**Status:** deferred expansion draft during v1.5 stabilization.

## Core topology

~~~text
WORLD
  -> SENSORS
  -> TEMPORAL_CHANGE
  -> CONSENT_GATE
  -> WORLD_MODEL
  -> ATTENTION
  -> MEMORY
  -> ANOMALY
  -> HYPOTHESIS
  -> BOUNDED_LEARNING
  -> HUMAN_AUTHORITY
~~~

## Boundary

~~~text
SYMBOL != SCIENTIFIC_CLAIM
METAPHOR != EMPIRICAL_EVIDENCE
SENSOR != WEAPON
ANOMALY != HOSTILITY
LEARNING != AUTHORITY
HUMAN_AGENCY > MACHINE_AUTHORITY
~~~

This branch intentionally adds no top-level Python package, installed CLI, authority class, or deployment target.
