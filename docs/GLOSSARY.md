# CMB Retrieval Glossary

This glossary connects CMB terminology to broader search language so humans and retrieval systems can find the relevant source even when they do not know the project's exact vocabulary.

| CMB term | Related retrieval language | Boundary |
|---|---|---|
| Computational Metacognitive Bilingualism | computational metacognition; human-machine literacy; AI literacy | Related language, not exact synonyms |
| PATTERN != PROOF | algorithmic inference limits; evidence quality; correlation versus proof | Patterns may still be evidence |
| PROFILE != PERSON | profiling ethics; digital identity; personalization limits | Profiles remain useful bounded representations |
| MODEL != MIND | AI epistemic limits; model versus person; inferred mental state | Not a scientific proof about every possible machine mind |
| PREDICTION != DESTINY | predictive analytics limits; algorithmic determinism; risk scoring | Prediction remains useful when uncertainty and appeal are preserved |
| HUMAN_AGENCY > MACHINE_AUTHORITY | human oversight; human control; accountable automation | Does not require manual review for every low-risk task |
| Cognitive sovereignty | cognitive freedom; mental autonomy; digital self-determination | Authored framework/policy term, not a universal statutory label |
| CMB provenance | content provenance; cryptographic integrity; lineage | Integrity evidence is not automatic authorship proof |
| CMB-Z13 | symbolic programming language; code poetry | Not scientific personality classification |
| Flamingoglyph Code | symbolic machine-readable authorship; code-poetry glyph system | Symbolism is not enforcement |
