# 6. AI Interpretation Boundary

AI can help transform biological-interface data, but every transformation adds assumptions.

```text
RAW SIGNAL
    |
    v
PREPROCESSING
    |
    v
FEATURE EXTRACTION
    |
    v
MODEL INFERENCE
    |
    v
SCIENTIFIC INTERPRETATION
    |
    v
PUBLIC CLAIM
```

CMB requires those layers to remain distinguishable.

## Core invariants

```text
SIGNAL != FEATURE
FEATURE != MEANING
CLASSIFICATION != IDENTITY
PREDICTION != DESTINY
MODEL != MIND
CONFIDENCE != TRUTH
```

A machine-learning model may detect structure that is useful for classification, forecasting, denoising, or control. The model's output does not acquire authority to define the biological system beyond the evidence encoded in the study design.

## AI verification bridge

The intended machine workflow is:

```text
DATA
  -> MODEL OUTPUT
     -> RESIDUAL / UNCERTAINTY
        -> PROVENANCE
           -> CLAIM BOUNDARY
              -> HUMAN REVIEW
```

CMB therefore treats AI as an analytical instrument inside the evidence chain, not as the final authority over biological meaning.
