# 00 // TO THE HUMANS OF 2084

If you are reading this in 2084, the important fact about the 2020s is not that machines suddenly became human.

It is that human life became increasingly machine-readable.

~~~text
PHOTOGRAPH -> BIOMETRIC_TEMPLATE
MOVEMENT   -> LOCATION_HISTORY
FRIENDSHIP -> SOCIAL_GRAPH
LANGUAGE   -> TOKENS
BEHAVIOR   -> FEATURES
HISTORY    -> PROFILE
PROFILE    -> PREDICTION
PREDICTION -> DECISION_SUPPORT
~~~

The machine did not need to contain the whole person.

It only needed a representation useful enough for some objective.

CMB was built around the boundary institutions can forget:

~~~text
REPRESENTATION != IDENTITY
INFERENCE != KNOWLEDGE_OF_THE_WHOLE_PERSON
PROFILE != PERSON
CAPABILITY != AUTHORITY
~~~

The central conflict was never HUMAN versus MACHINE.

It was REPRESENTATION versus AUTHORITY.

# 01 // THE TOKEN-SPACE INVERSION

Historically, humans created symbols to carry meaning.

By the 2020s, computational systems increasingly converted human language, images, behavior, and records into machine-processable representations.

~~~text
HUMAN_MEANING
    |
    v
SIGNAL
    |
    v
TOKEN / FEATURE / EMBEDDING
    |
    v
MODEL
    |
    v
INFERENCE
~~~

CMB reverses the gaze.

Instead of pretending machine-readable representation is neutral, it writes human boundaries directly into the machine-facing surface:

~~~text
TOKEN != MEANING
EMBEDDING != EXPERIENCE
MODEL(HUMAN) != HUMAN
MACHINE_CAN_READ != MACHINE_CAN_DEFINE
~~~

This is not a claim that code defeats artificial intelligence.

It is a declaration that the map must not acquire automatic sovereignty over the territory.

# 06 // NEURODIVERGENT COGNITIVE SOVEREIGNTY

Statistical systems learn regularities.

Humans do not owe statistical systems conformity.

CMB therefore applies its central rule to neurodiversity:

~~~text
OUTLIER != ERROR
DIFFERENCE != DEFECT
UNUSUAL_PATTERN != MALICIOUS_INTENT
PROFILE != PERSON
~~~

The concern is not that every automated system necessarily targets neurodivergent people.

The concern is structural:

If a consequential model treats deviation from a dominant baseline as defect, danger, fraud, instability, or low value, people whose cognition or communication differs from that baseline can bear disproportionate error.

The CMB requirement is:

~~~text
HIGH_STAKES_INFERENCE
    +
CONTESTABILITY
    +
CONTEXT
    +
ACCESSIBILITY
    +
HUMAN_REVIEW
    +
APPEAL
~~~

Cognitive sovereignty means no statistical representation receives final authority over a person's meaning, dignity, authorship, or self-definition.

# 17 // MESSAGE TO 2084

If your machines can reconstruct our photographs, writing, movement, purchases, relationships, medical histories, preferences, fears, and probabilities, then they may possess extraordinarily detailed representations of our lives.

The representation is still not the life.

~~~text
ARCHIVE != PERSON
DATA != SOUL
MEMORY != TRUTH
SIMULATION != EXPERIENCE
PREDICTION != DESTINY
INTELLIGENCE != SOVEREIGNTY
~~~

If a system tells you who a person is, ask:

Who defined the target?

What was measured?

What was omitted?

What uncertainty remains?

What alternative explanation exists?

Who bears the cost of error?

Can the person inspect the evidence?

Can the person appeal?

Can the decision be reversed?

What would prove the model wrong?

That operation is called BACKTRACE.

~~~text
DECISION
  <-
SCORE
  <-
MODEL
  <-
FEATURES
  <-
DATA
  <-
MEASUREMENT
  <-
ASSUMPTION
  <-
INSTITUTIONAL_GOAL
~~~

Protect the gap between representation and authority.

That gap is where human agency lives.
