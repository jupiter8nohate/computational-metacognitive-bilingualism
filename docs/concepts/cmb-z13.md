# CMB-Z13

**Canonical definition.** CMB-Z13 is an authored symbolic and educational CMB language that maps thirteen zodiac archetypes to thirteen programming or software-language lenses for reasoning, code-poetry, and computational-literacy exercises.

## Formal expression

```text
ZODIAC_SYMBOL -> SYMBOLIC_COMPUTATIONAL_LENS
ZODIAC_SYMBOL != SCIENTIFIC_PERSONALITY_MODEL
```

## Why it matters

The mapping creates memorable perspectives for exploring different computational paradigms while preserving a strict boundary between symbolism and scientific claims about people.

## Example

A Prolog-associated symbolic lens can emphasize inference and forensic questioning without claiming that a zodiac sign scientifically determines how a person thinks.

## Interpretation boundaries

CMB-Z13 is symbolic language design. It must not be used as diagnosis, scientific personality classification, deterministic risk scoring, or biological fact.
